# Project Scope

## Objective

Build a portfolio-quality Analytics Engineering project demonstrating:

* Snowflake
* dbt
* SQL
* Git/GitHub
* Dimensional Modeling
* Data Quality Testing
* Business Metric Definitions
* Documentation

using a realistic e-commerce dataset.

## Phase 1 Scope

### Data Sources

* Orders
* Order Items
* Payments
* Customers
* Products
* Sellers

### Data Platform

* Snowflake

### Transformation Framework

* dbt

### Modeling

* Staging Layer
* Intermediate Layer
* Fact Tables
* Dimension Tables

### Data Quality

* Source freshness checks
* Uniqueness tests
* Not-null tests
* Relationship tests

### Metrics

* Revenue
* Orders
* Average Order Value
* Active Customers
* Revenue by Product Category
* Revenue by Seller

### Documentation

* Business Requirements
* Metric Definitions
* Architecture
* Data Model

## Out of Scope (Phase 1)

* Machine Learning
* Forecasting
* Real-time Processing
* Streaming Data
* Complex Customer Segmentation
* External APIs

## Success Criteria

A hiring manager should be able to review the repository and understand:

1. The business problem.
2. The data model.
3. The dbt architecture.
4. The testing strategy.
5. The metric definitions.
6. The final reporting outputs.
