# Project Scope

Question Answered:
What is included in the project?

Purpose:
Define project boundaries and deliverables.

## Objective

Build a portfolio-quality Analytics Engineering project demonstrating:

* DuckDB
* dbt
* SQL
* Git/GitHub
* Dimensional Modeling
* Data Quality Testing
* Business Metric Definitions
* Documentation

using a realistic e-commerce dataset.

## Phase 1 Scope

### Data Sources

* Orders
* Order Items
* Payments
* Customers
* Products
* Sellers
* Reviews
* Geolocations

### Modeling

* Staging Layer
* Intermediate Layer
* Fact Tables
* Dimension Tables

### Data Quality

* Source freshness checks
* Uniqueness tests
* Not-null tests
* Relationship tests

### Metrics

* Commercial Performance
* Customer Analytics
* Logistics & Fulfillment
* Customer Satisfaction

### Documentation

* Business Requirements
* Metric Definitions
* Architecture
* Data Model

## Success Criteria

A hiring manager should be able to review the repository and understand:

1. The business problem.
2. The data model.
3. The dbt architecture.
4. The testing strategy.
5. The metric definitions.
6. The final reporting outputs.
7. The reasoning behind major design decisions.
